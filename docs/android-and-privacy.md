# Life 0.6: первый запуск и приватность

Главная → «Твоя жизнь, по полочкам»: формы с примерами. Пример не сохраняется до подтверждения формы. «Посмотреть заполненный пример» добавляет 11 помеченных demo записей. Они учитываются в сводках. «Убрать примеры» удаляет также изменённые тестовые записи и оплаты тестовых услуг. Не связывайте реальные учебные занятия с тестовым курсом.

Музыка: кнопка ♫ → выбрать файлы. Плейлист живёт до закрытия/перезагрузки страницы. Blob URL доступны только локально; музыка не публикуется. Встроенной лицензированной музыкальной библиотеки нет. Воспроизведение в фоне зависит от браузера/Android.

Android: открой сайт через Chrome с интернетом, дождись установки офлайн-файлов (Ещё), установи через меню браузера, закрой все окна Life и открой снова, проверь авиарежим. Очистка данных браузера/сайта может удалить записи и кеш. Делай JSON-копии и храни приватно. После обновления закрывай все окна Life для активации новой версии.

Данные: localStorage life-v1, настройки life-dashboard. Серверной синхронизации нет. Публичен исходный код, а не пользовательское хранилище. Данные не зашифрованы. Скрипты того же origin могут читать localStorage; разные пути GitHub Pages одного владельца не обеспечивают изоляции. Компрометация сайта/аккаунта публикации тоже представляет риск. Не хранить пароли, ключи, документы и чувствительные финансовые реквизиты. JSON-экспорт открытый, не включать его в репозиторий.

Для полной независимости: будущий подписанный Android APK с ресурсами внутри пакета, локальной зашифрованной БД, ключом через Android Keystore, разблокировкой через системную биометрию и зашифрованным экспортом. APK в этом обновлении не создан. PWA работает офлайн после установки кеша, но источник установки и обновлений остаётся сайтом.

Разработчику: при изменении оболочки повышать CACHE в sw.js и версии ресурсов в index.html и FILES одновременно. Install использует addAll: неполный кеш не активируется. Не кешировать личные API-ответы. Нет skipWaiting, чтобы не смешивать оболочки активных вкладок.
