# Life 0.8 — рабочий кошелёк

Деньги → Рабочий кошелёк.

- Начисление за день: сумма из рабочего приложения, дата записи, рабочий день, статус «В обработке» / «Доступно».
- Корректировка: положительная сумма для доплаты, отрицательная для удержания. Дата записи и рабочий день могут различаться. На графике сумма относится к рабочему дню.
- Вывод на карту: завершённый перевод уменьшает рабочий кошелёк и увеличивает карту. Повторного дохода нет. Ожидающий перевод отображается отдельно и до подтверждения не меняет остатки.
- Начальный остаток: деньги, которые были до начала учёта. Не считаются доходом. Для кошелька отдельно можно задать доступный остаток и остаток в обработке.
- Обычный расход: положительная сумма, выбранная дата и счёт списания. Удержания из заработка следует заносить корректировками, чтобы не смешивать их с покупками.

Нет автоматического импорта/синхронизации с рабочим приложением. Остатки выводятся только из внесённой истории. Статусы изменяются вручную. Отрицательный остаток не исправляется автоматически: он может означать неполную историю или отсутствие начального остатка.

Старые income/expense без счёта относятся к «Карта / наличные». Уже записанный доход можно открыть и сменить его тип на вывод, если это была выплата из рабочего кошелька. Запись заменяется по тому же id, а не дублируется. Подтверждённые оплаты подписок сохраняют прежний порядок исправления через удаление связанной оплаты.

Хранилище life-v1, appId ru.vovan20.life, origin https://localhost и ключ подписи прежние. Новые типы — work и opening; JSON-экспорт версии 1 сохраняет все записи, обновлённый импорт их проверяет. Старые версии Life не смогут импортировать новые типы; не понижайте версию после обновления. Само обновление не преобразует и не удаляет записи.

Проверено: расчёты отрицательных корректировок, даты рабочего дня, статусы, отсутствие двойного дохода при выводе, исходные записи и начальные остатки; реальные формы в Chromium, сохранение после перезагрузки и экспорт/импорт. Скриншоты пользователя не импортировались в данные. Проверка установки/обновления на физическом Android остаётся необходимой.
