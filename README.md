# Life — ядро личной системы

Первый рабочий слой системы Вована: финансы, услуги, проекты, задачи, календарь, обучение и пользовательские разделы. Это бэкенд, а не готовое мобильное приложение.

## Что работает

- REST API `/api/v1`, OpenAPI `/openapi.json`, интерактивное описание `/docs`.
- Вход по паролю, отзыв сессии, срок сессии 12 часов. Пароли хранятся как scrypt-хеши, токены — как SHA-256-хеши.
- Изоляция данных по пользователю, UUID, связи между записями, журнал изменений, проверка версий при редактировании.
- Счета, начальные остатки, доходы, расходы, переводы, получение и возврат займа. Суммы в копейках, валюты считаются отдельно. Операции неизменяемые.
- Услуги: серверы, SIM, подписки, произвольные реквизиты, баланс провайдера (в том числе отрицательный или неизвестный).
- Будущие обязательства: разово, каждые N дней, каждые N календарных месяцев/лет. Подтверждение оплаты атомарно создаёт расход. Повторный запрос не дублирует списание.
- Проекты, задачи, события, занятия с результатом, маршруты обучения. Процент относится только к шагам конкретного курса.
- Пользовательские типы с полями text/integer/boolean/date и проверкой значений.
- Календарь собирает задачи, события, занятия, платежи и операции из общей базы.
- CSV-экспорт операций для Excel (UTF-8 BOM, защита от формул в текстовых полях).

## Быстрый локальный запуск

Python 3.12+, команды из `backend/`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m alembic upgrade head
python -m life.cli create-user vovan
python -m uvicorn life.api:app --host 127.0.0.1 --port 8000
```

Пароль вводится скрыто, минимум 12 символов. Открыть `http://127.0.0.1:8000/docs`, выполнить `auth/login`, затем вставить выданный токен в Authorize. SQLite используется только для локальной разработки. Для PostgreSQL задать `DATABASE_URL=postgresql+psycopg://...` до миграции и запуска.

## PostgreSQL и Docker

Из корня проекта:

```bash
cp .env.example .env
# Заменить POSTGRES_PASSWORD на случайный hex-пароль, .env не коммитить.
docker compose up --build -d
docker compose exec api python -m life.cli create-user vovan
```

Миграции выполняет отдельный контейнер перед API. База доступна только внутри сети Docker; API опубликован на `127.0.0.1:8000`. Для телефона нужен отдельный хостинг API и HTTPS reverse proxy. GitHub Pages запускает только клиентский интерфейс; Python и PostgreSQL там не запускаются. CORS_ORIGINS — точные origins без пути `/Life/`, например `https://v0van200.github.io`.

Перед публичным запуском обязательны HTTPS и ограничение частоты `/api/v1/auth/login` на reverse proxy. Секреты и токены не помещать в код Pages. Сейчас нет регистрации из интернета: пользователей создаёт администратор через CLI. Двухфакторная авторизация и восстановление по email ещё не реализованы.

## Проверки

```bash
cd backend
python -m pytest -q
python -m alembic upgrade head
python -m alembic check
```

GitHub Actions проверяет SQLite и PostgreSQL. Для локального PostgreSQL-набора можно указать TEST_DATABASE_URL: тесты удаляют и создают все таблицы, поэтому использовать **только отдельную тестовую базу**.

## Граница текущей версии

Нет интерфейса, публично развёрнутого API, уведомлений, банковских интеграций, двусторонней синхронизации с Excel, XLSX-импорта, почасового биллинга, обмена валют и автоматического распределения возвратов по займам. CSV — экспорт, не основная база данных. Пока календарь использует UTC; пользовательский часовой пояс и привычки/планировщик дня — следующие модули. Система не заявляется готовой к высокой нагрузке: массовые отчёты и индексы нужно оценивать на реальных объёмах.
